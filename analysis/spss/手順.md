# SPSS で混合モデルを回す手順

このフォルダの `ui_spss.csv` を SPSS で開いて、混合モデルを当てます。
列の意味は `列の説明.xlsx` にあります。

CSV は `python -I ../00_準備.py <書き出しの日付>` で作り直せます。

---

## 1. データを読み込む

1. SPSS を起動
2. **ファイル → 開く → データ**
3. ファイルの種類を **CSV (*.csv)** にして `ui_spss.csv` を選ぶ
4. テキストインポートウィザードが出たら
   - 区切り記号は **カンマ**
   - **最初の行を変数名として使う** に チェック
   - 文字コードは **UTF-8**
5. 読み込んだら **変数ビュー** を開いて、尺度を直す

| 列 | 尺度 |
|---|---|
| `pid` `input` `leg` `slot` `grp` `run_id` `scene_id` `stop_name` `day` | 名義 |
| `numpad` `unknown_btn` `yuki` `eve` `switch_new` | 名義 |
| `seq_all` `seq_method` `cnt` `cls` `cond_nth` | スケール |
| `t_*` `log_t_*` `taps_*` | スケール |

---

## 2. メニューで回す（こちらが本線）

**分析 → 混合モデル → 線形**

### 2-1. 最初の窓（被験者と反復）

- **被験者** の箱に `pid` を入れる
- 「続行」

### 2-2. 本体の窓

| 箱 | 入れるもの |
|---|---|
| **従属変数** | `log_t_input` |
| **因子** | `input` `unknown_btn` `switch_new` |
| **共変量** | `seq_all` `seq_method` |

### 2-3. 固定ボタン

次を「モデル」に追加する。

- `input`（主効果）
- `seq_all`（アプリ全体への慣れ）
- `seq_method`（その方式での慣れ）
- `input * seq_method`（**慣れ方が方式で違うか。調べたい交互作用**）
- `switch_new`（切り替え直後）
- `unknown_btn`

「切片を含める」に チェック。

### 2-4. 変量ボタン

**1つ目**

- 「切片を含める」に チェック
- **共変量** に `input` を入れる（＝変量傾き）
- **被験者の組み合わせ** に `pid`
- 共分散タイプ **無構造（UN）**

**2つ目**（「次へ」で追加）

- 「切片を含める」に チェック
- 被験者の組み合わせ に `run_id`
- 共分散タイプ **分散成分（VC）**

**3つ目**（「次へ」で追加）

- 「切片を含める」に チェック
- 被験者の組み合わせ に `scene_id`
- 共分散タイプ **分散成分（VC）**

### 2-5. 推定ボタン

- 方法は **制限付き最尤法（REML）**

### 2-6. 統計量ボタン

- **固定効果の推定値** に チェック
- **共分散パラメータの検定** に チェック

「OK」で実行。

## 4. 結果の見かた

| 表 | 見るところ |
|---|---|
| **固定効果の推定値** | `input` の推定値 B。**exp(B) が「テンキーは＋−ボタンの何倍か」** |
| 同上 | `input * seq_method` が有意かどうか |
| **共分散パラメータの検定** | `pid` `run_id` `scene_id` の分散。**0 に近ければその変量効果は効いていない** |
| 警告 | **「反復が収束しませんでした」「特異」が出たら、そのままの結果は使わない** |

## 5. 気をつけること

- **`corrections` 列は使わないこと。** ⌫ を数え落としていて、＋−ボタン側は構造上ゼロになる
- `log_t_input` は 1ms 未満を 1ms に置き換えてから対数をとっている
- `t_make` 単独は使わない。1タップで終わった回が 0 になるため
- **場面（`scene_id`）の変量効果は必ず入れること。** 同じ便の同じ停留所にいた
  2人の残差は相関しており（ICC 15%、p<0.001）、独立ではない。
  2件以上ある場面が 370 個あるので、分散は推定できる
- **場面を外すと、テンキーの係数の誤差が小さく出すぎる**（p値が甘くなる）。
  入力方式はほとんどの便で全員同じなので「層のあいだ」の変数に近いため
- どうしても収束しないときだけ外す。そのときは原稿に
  「場面の変量効果を外したため、誤差を小さく見積もっている可能性がある」と書く
- 停留所の種類（`stop_name`）は入れなくてよい。ICC 0.5%、p=0.30 でほぼ独立。
  「大きな駅前は数えにくい」という固定的な難しさは見あたらなかった
