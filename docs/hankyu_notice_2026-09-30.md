# 阪急バス（吹田営業所）への実施連絡（2026-09-30）

2026-09-17 にいただいた条件付き承諾の**条件④「実施日時・便が確定したら管轄営業所へ連絡」**
に基づく連絡。**下のコードブロックの中がそのまま送信本文**（約900字）。

> ### ⚠️ 送る前に決めること
> **実施日がまだ確定していない**（参加者の都合に合わせるため。`docs/operation_plan.md` §3）。
> 営業所は運転士へ連携するので、**候補日の羅列では受け取っても使えない**可能性が高い。
> 下の本文は「**便と人数は確定、日付は候補期間＋1週間前に確定連絡**」という形で書いてある。
> 日付が固まるまで待つ選択肢もある。

```
阪急バス株式会社 吹田営業所 ご担当者様

お世話になっております。
大和大学 4年の松本大地と申します。

2026年9月に、車内の乗車人員の計測についてご相談し、
条件付きでご承諾をいただきました。その際に「実施日時・便が
確定したら管轄営業所へご連絡を」とのご指示をいただきましたので、
ご連絡いたします。

■ 乗車する便（すべて吹田市内線2系統）

 ① ＪＲ吹田駅（北口）12:49発 → 桃山台駅 13:24着
 ② 桃山台駅 13:48発 → ＪＲ吹田駅（北口）14:22着
 ③ ＪＲ吹田駅（北口）16:20発 → 桃山台駅 16:55着
 ④ 桃山台駅 17:18発 → ＪＲ吹田駅（北口）17:52着

②と④はＪＲ吹田駅（南口）まで運行される便ですが、
学生は北口で下車いたします。

1日に①②、または③④の2便に乗車します。

■ 人数

1便あたり学生5名（人数を入力する役3名、乗降を数える役2名）です。
運賃は全員が各自で正規にお支払いします。

■ 車内で行うこと

 (1) 3名が着席または手すりにつかまった状態で、停留所ごとに
   車内のおおよその人数を自分のスマートフォンに入力します。
 (2) 2名が前扉・後扉付近で、つかまった状態のまま乗車・降車の
   人数を数え、手元の用紙に記録します。

いずれも走行中に車内を移動することはございません。

■ 行わないこと

カメラによる撮影・録音は一切いたしません。個人が特定される情報は
記録せず、記録するのは人数の数値のみです。他のお客様へのお声がけ、
アンケート、機材の設置も行いません。

■ 実施日

10月中旬から11月中旬の平日のうち、8日を予定しております。
参加する学生の都合に合わせて日程を組んでいるため、
現時点では確定しておりません。

確定次第、実施日を改めてご連絡いたします。実施の1週間前までには
お知らせできるよう進めてまいります。

お手数をおかけいたしますが、どうぞよろしくお願いいたします。

大和大学
松本大地
23610225tm@stu.yamato-u.ac.jp
```

## この本文に入れたこと・入れなかったこと

| | 判断 |
|---|---|
| **系統番号（2系統）** | 入れた。営業所が運転士へ連携するのに要る |
| **4便の発着時刻** | 入れた。これが連絡の主目的 |
| **②④が南口まで行く便で、北口下車であること** | 入れた。運転士が「降り忘れ」と誤解しないため |
| **1便5名の内訳** | 入れた。前後扉に立つ2名がいることを先に伝えておく |
| **走行中に移動しない旨** | 入れた。**承諾条件①**への回答になる |
| **撮影・録音なし** | 入れた。当初の問い合わせで約束した内容 |
| 群・条件・アンケート・研究の仮説 | **入れなかった。** 事業者には関係がなく、長くなるだけ |
| 具体的な日付16日の羅列 | **入れなかった。** 確定していないものを送っても運転士へ連携できない |
| 交通費・謝礼の話 | **入れなかった。** 運賃は各自正規払いとだけ書けば足りる |
