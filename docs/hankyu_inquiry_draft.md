## 1. 研究計画の要旨（先生のご判断用）

### 目的
将来、バスの乗車人員を自動測定する技術を実用化する際には、その精度を検証するための
**正解データ**が必要になります。本研究は、その正解データを**人手でどう正確に集めるか**を
検討するものです。具体的には、乗客がスマートフォンで車内人数を報告する方法をとった場合に、
記録のしかたによって集まる数値がどう変わるかを調べます。

### 実施内容
1. 学生が一般の乗客として乗車し、**停留所ごとに車内のおおよその人数をスマートフォンに入力**する
2. 別の学生2名が前扉・後扉の付近で、**乗車人数と降車人数を数えてスマートフォンに記録**する
   （始発からの増減を積み上げると、各停留所の車内人数が分かる）

### 実施しないこと（問い合わせ文でも明記します）
- カメラによる撮影、録音
- 個人が特定される情報の記録（記録するのは人数の数値のみ）
- 他のお客様への声かけ、アンケート、ビラ配り
- 車内での機材の設置

### 規模・時期

| 項目 | 内容 |
|---|---|
| 事業者 | 阪急バス（吹田営業所管内） |
| 路線 | 1系統に固定。**始発から終点まで乗車**（人数の積み上げに必要なため） |
| 時期 | 2026年10月〜11月の平日夕方、4〜6日程度 |
| 1便あたり | 学生5〜6名（人数を入力する役3〜4名＋乗降を数える役2名） |
| 運賃 | 全員が正規の運賃を各自で支払います |

### なぜ夕方・なぜ通し乗車か
- 夕方は1回の乗車の中で車内の混み具合が変化するため、空いている状態と混んでいる状態の
  両方のデータが取れます
- 乗降人数の積み上げで車内人数を出すには、車内が空の**始発から乗る**必要があります
