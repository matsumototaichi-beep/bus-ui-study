# 指導教員への報告 文案（2026-09-25）

作成：2026-09-25 ／ 送信者：松本
方針：いただいた助言をどう反映したかを述べる。**誤りの指摘が目的ではない**ので、
事実の食い違いは「確認した結果」として淡々と一行で触れるにとどめる。
判断をお願いしたい点は最後に2つだけ置く。

---

```
先日いただいた混雑の情報と、その前の「数えられる便をベースにする」というご助言について、
確認と設計の組み直しを行いましたので報告します。

■ 方向によるピークの違いは、いちばん設計に効きました

私たちが先行実験（9/18）で乗ったのは桃山台駅→JR吹田駅（北口）の方向だけで、
逆方向は測っていませんでした。JR吹田駅（北口）→桃山台駅が夕方の本当のピークで、
始発の時点で満席になるというご指摘は、混雑条件の選択肢を一つ増やしてくれました。

■ ただ、混雑条件は現行の便で足りていました

先行実験の実測では、桃山台駅17:18発の便で車内が8人から39人まで増え、
まさにその区間で目視が崩れています（私の記録に「正直この辺から車内人数は適当」と
残っています。逆算した実数とアプリの回答が最大10人ずれました）。

いただいた資料はこの便を「立ち客が出る程度で、すし詰めになることは滅多にない」と
評価しています。それはそのとおりです。ただ、実験にとっては、
その程度でもう正確な人数が取れなくなります。すし詰めである必要はありませんでした。

そこで「混んでいる便」は、実測済みの桃山台駅17:18発を主軸にします。

・8人から39人まで増えるので、1回の乗車で「数えられる→数えられない」の境目をまたぐ
・同じ人が同じ便の中で両方の状態を経験するので、人による差が入らない
・19時台まで引っ張らずに済むので、参加者が集まりやすい

ご指摘のJR吹田駅（北口）発17:30以降は、全区間が「数えられない」領域になるため、
混雑条件の純度が要る場合の予備として残します。

■ 路線を変えない方針は、ご指摘と整合していました

「吹田駅発着で終日ガラガラの路線は基本的にない」というご指摘は、
先日決めた方針（路線は吹田市内線2系統のまま変えず、便の時間帯を変えて
「空いている便」と「混んでいる便」の2水準を作る）を裏づけるものでした。

路線・区間・停留所・所要時間・運賃・のりばがすべて同じで時間帯だけが違うので、
混雑以外の条件差が入りません。別の路線を立てるより交絡が少ない構成になります。

「日中9:00〜16:00は落ち着いている」というご指摘も、私たちの見立て（15時台で5〜15人）
と一致していました。空いている便は15時台を使います。10時〜14時台はさらに空きますが、
参加者（学生）が授業で来られないため、15時台が現実的な上限だと考えています。

■ 混雑の公開データは存在しませんでした

系統別・便別の乗車人員は、阪急バス・吹田市・豊中市のいずれも公表していませんでした。
吹田市統計書は事業者単位の年間値まで、豊中市統計書はバス停単位で主要10停留所までです。

したがって「どの便がどれくらい混むか」は、実際に乗って数えるしかありません。
現時点で数字があるのは9/18に私が乗った1便だけです。
本実験では計数役2名（前扉・後扉）を置き、始発の0人から積み上げて基準値を作ります。

■ 研究の組み直し

ご助言を受けて、問いを3本立てにしました。

RQ1（空いている便）数えられる状況で、どの回答UIが良いか
  → 入力方式（ステッパー／テンキー）と「わからない」ボタンの有無の2×2

RQ2（混んでいる便）正確な人数の代わりになる指標は何か
  → 第一候補は、すでにアプリにある「混雑度6段階のクラス」そのもの

RQ3 空いている便で作った「指標→人数」の関係は、混んでいる便に外挿できるか

位置づけは「移動中のバス車内で正確な乗車人数は測れない。しかし混んでいるかどうかは
取れる。そして混雑時には人数の代わりになる手がかりがある」としました。

クラスを第一候補にしたのは、アプリの改修が要らず、1タップで答えられるので
混雑時にも欠損しにくいからです。検証の要になるのは
「混雑時にクラスの一致度（同じ便に乗った複数名の回答が揃うか）が落ちるかどうか」です。
人数が混雑時に崩れることは分かっていますが、クラスの一致度まで崩れるなら
「混んでいるかどうかも取れない」ことになり、この位置づけ自体が成立しません。
反証されうる形にしてあります。

なお混雑度は、これまで「統制できないので事後に層別する変数」として扱っていましたが、
便の時間帯で水準を作れるようになったので、操作する要因に格上げしました。

■ ご判断いただきたい点

① 遅い回（17時台集合・19時前後解散）を設けてよいか
   時間帯そのものが要因になったので、遅い便も必要です。ただし参加者が集まりにくく、
   解散が遅くなります。早い回を主軸にし、遅い回は必要な本数だけに絞る方針で
   よいでしょうか。

② 参加者の交通費の手続き
   総額は1万3千〜1万5千円程度の見込みです。大学から出るものと思っていますが、
   どの費目で、謝金扱いか実費精算か、証憑は何が要るか、事前申請が要るかが
   分かっていません。事務へ確認する際の窓口と進め方をご教示いただけると助かります。

進捗としては、アプリは実装と動作確認を終えて公開済み、事後アンケートの設計と
計数役の記録用紙も用意できています。残るのは条件割当表の作成と、
実施日の調整（参加者の都合に合わせます）です。
```

## この文案に入れなかったもの

| | 理由 |
|---|---|
| いただいた情報が生成AIの出力と思われること | 指摘しても設計は変わらない。内容の当否だけ扱えば足りる |
| 「吹田市民病院前」が2系統の経路上に見当たらないこと | 停留所辞書（阪急バス736件）に無い。吹田市民病院は2018年に岸部新町へ移転しており、方角がJR岸辺側。**ただし辞書が令和4年度版なので断定を避けた**。公式での照合結果が出たら、必要なら一行で触れる |
