A

このQRを読み取ってください

スマホのカメラアプリで読み取ってください

https://matsumototaichi-beep.github.io/bus-ui-study/

開いたらすること

  1. 「ログイン」タブを選ぶ（「新規登録」ではありません）
  2. 配布カードの ID と パスワード を入力
  3. うまくいかないときは「パスワードを表示して確かめる」にチェック
  4. ログインできたら実験者に見せてください

※ LINE や Discord の中のブラウザでは開かないでください。カメラアプリから開いてください。
