## 5. 乗り間違いを防ぐ

桃山台駅〜阪急南千里駅〜亥子谷の区間は **2・3・5・8・9・10・11 の7系統が重なる**。
とくに3系統は2系統と起終点が同じ（ＪＲ吹田駅（南口）⇔桃山台駅）で吹田側の経路だけが違うため、
乗り間違えるとデータ上で見分けがつかない。

| | 対策 |
|---|---|
| **1本目（北口発）** | **①のりばに並べばよい。** ①＝[2]桃山台駅ゆき・[2]亥子谷ゆき、②＝[5]・[4]。**3系統は北口を通らない**（南口のりば2のみ）ので、3系統との取り違えは構造的に起きない |
| **2本目（桃山台発）** | 7系統が重なるので、**行先番号[2]と「ＪＲ吹田駅（北口）ゆき」を目視で確認**してから乗る。平日の桃山台発は12:48〜16:24が 2・2・3 の順で3系統が混ざり、16:48以降は2系統が続く |
| 共通 | 参加者には「実験者が指定した1本にだけ乗る。来た順に乗らない」と明示する |

**便の指定は系統番号だけでは足りない。** 同じ2系統でも運行区間が便ごとに違う
（南口まで行く便／北口で終わる便／亥子谷止まりの便）。
**起点・発車時刻・行先**をセットで指定すること。

なお2本目（桃山台17:18発）は北口止まりではなく、**ＪＲ吹田駅（南口）18:03まで行く便**。
参加者と計数役は**北口（17:52）で降りる**。乗り過ごさないよう説明で念を押す。

## 6. 基準値（計数役）

前扉・後扉に1名ずつ。記録用紙は `docs/counting_sheet.html`（A4片面・1便1枚・係ごとに1枚）。

| | 0からの積み上げ |
|---|---|
| **1本目**（北口15:49発） | **北口は始発ではない。** 2系統は南口〜吹田市役所前〜北口と来るので、北口の時点で先客がいる。**乗車前に車内人数を1回数えて初期値とする。** 15時台なら5〜15人なので数えられる |
| **2本目**（桃山台17:18発） | **桃山台駅が始発なので0人から積める。** 先行実験で終点ちょうど0に閉じることを実証済み |

終点で「乗車合計 − 降車合計 ＝ 0」を2人で突き合わせる。
0にならない便は**基準値なしとして捨てる**（無理に合わせない）。
