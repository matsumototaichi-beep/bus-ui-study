# 2026-10-06 アンケートを1本に統合した

## 1. きっかけ

松本から確認があった。

> アンケートは、昼便の行って、帰ってで1です。そして夕方も同じものを用いればいいですよね?
> となると、2日分が終わった後のアンケートでもう一つ準備する必要もありますか??
> 一つのアンケートで完結しませんか??

前半の理解は正しい。**①「今日の分」は昼の日にも夕方の日にも同じものを使う**（設計どおり）。
問題は後半、**②「まとめ」が本当に要るのか**。

## 2. ②を別にしていた理由と、その崩し方

②に入れていたのは S2（2つの入力方式の比較）・S5（SUS）・S6（自由記述）。
**S2 が理由だった。** 入力方式は実施日ごとに固定なので、1日目の時点では片方しか経験していない。
だから「2つを並べて比べる」設問は最後に置くしかなかった。

**だが、聞き方を変えれば①に入る。**

松本の案：

> 2つを直接比較するというよりかは、どちらも同じアンケートを取って、
> その際のこたえやすさという欄を作って、その差を見る形で2つの比較を行う

これを採用した。**「今日使った入れ方はどうでしたか」を毎回まったく同じ設問で聞き、
2日分の点数の差を比較として使う。**

| | 旧（比べさせる） | 新（毎回同じ設問） |
|---|---|---|
| いつ答えるか | 2日目に1日目を思い出しながら | **その日の直後** |
| 記憶の薄れ | 影響する | **関係ない** |
| 提示順の影響 | 先に見せたほうが有利 | **2つを並べないので起きない** |
| 用紙・フォームの数 | 5 | **3** |

**松本が心配していた「1回目覚えているかな」という問題が、ここで完全に消えた。**

## 3. 新しい S2（今日使った入力方式について）

| # | 設問 |
|---|---|
| 2-0 | 今日の人数の入れ方はどちらでしたか（照合用・必須） |
| **2-1** | **今日の入れ方は、全体として答えやすかった** ★主指標 |
| 2-2 | 押しやすかった |
| 2-3 | 素早く答えられた |
| 2-4 | 思った通りの人数を入力できた |
| 2-5 | 揺れている車内でも押し間違えにくかった |
| 2-6 | 頭を使う・疲れると感じた（逆転項目） |
| 2-7 | 気づいたことがあれば（自由記述） |

**2-1 の2日分の差が、そのまま「どちらが答えやすいか」になる。**

旧版の強制選択（「2つのうち答えやすかったのはどちら」＋「それはなぜ」）は廃止した。
記憶に頼るうえ提示順の影響を受ける。**2-7 の自由記述が、その日の印象として同じ役割を果たす。**

旧 2-7（揺れる車内でどちらが押し間違えにくいか）も、強制選択から
**その日の5段階評価（2-5）**に移した。

## 4. 用紙・フォームは3つになった

| | いつ | 中身 | 版 |
|---|---|---|---|
| **① 前半** | 各実施日の解散直後（毎回） | S0・S1（1日目のみ）・S3・S2 | 1つ |
| **② 後半 A** | ①を回収・送信してから | S4 ＋ ★2日目だけ S5・S6 | v1・v2 |
| **② 後半 B** | 同上 | 同上（あり／なしの順だけ逆） | v3・v4 |

SUS と自由記述は後半の末尾に「★2日目の方だけ」の区切りを置いた。
Googleフォームなら1日目の人はそこで送信して終われる。

**版による違いは「わからない」ボタンの提示順だけになった。**
v1とv2、v3とv4は現在まったく同じ中身。後で順序を入れ替える設問を足すときのために4つのまま残す。

## 5. S3 を S2 より先に置いた

S2 に「思った通りの人数を入力できた」がある。これを先に聞くと、
S3-3「数えきれていないのにそれらしい数を入れたか」の答えが引っ張られる。
**いちばん答えにくい設問を、前の設問に汚されない位置に置く。**

順番：S0 → S1 → **S3** → **S2** → ［壁］ → S4 → ★2日目だけ S5・S6

## 6. 設問の置き場所を Excel 1か所にした

`tools/make_questionnaire.py` を書き直し、**Word も `設問一覧.xlsx` から作る**ようにした。
Googleフォーム生成（`tools/make_forms.py`）と同じ正本を読む。
**文言を直すときは Excel だけを直せばよい。二重管理にならない。**
