# 2026-09-12 教授との打ち合わせを受けた計画の立て直し

## 打ち合わせで出た論点（松本のメモより）
- **実施地**：3人などでバスに乗ると不審に思われトラブルになりうる → 避けたい。
  大学院経由で連携している**奈良交通**に依頼するのが最も確実。大阪は依頼がたらい回しになる恐れ・トラブル時が面倒。
- **課題**：奈良は遠い。謝礼なしで誰が来てくれるか。往復交通費とバス運賃を用意する手続きが面倒だが、はっきりさせる必要がある。
- **締切**：実験は11月中に終わらせる。
- **真値の問題**：乗車人数の真値が分からないのが最大の弱点。対外発表で攻撃されるのは目に見えている。
  「混雑時は正確に数えられないのでは」への答えも用意する（ラッシュ時に1人で乗って数えてみる個人試行など。研究データには使わない）。
- **評価の観点**：使いやすさで走るか、正確な人数が取れるかの観点か、を決める。
- **UIの設計思想**：デモのアプリから、iPhone/iPod のような「こだわりの哲学」が感じられない。
  Claude がどういう基準で部品を配置したかを説明させ、松本が本を読んで改善を指示する。
  いくつかのパターンを作って比較する。院進後に「なぜこの形か」を説明できるようにする。
- **進め方**：詰まったら教授に質問 or コミットして GitHub で共有。会話が長くなったら教授が要約。
  AIの調査は**アブストだけで判断しない。論文の本文PDFを読ませる**。
