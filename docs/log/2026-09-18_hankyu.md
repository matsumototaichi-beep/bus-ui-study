## 3. Supabaseにテーブル作成

`ui_responses.sql` → `ui_sessions.sql` → `ui_report_feed.sql` の順に、松本がSupabase SQL Editorで実行。

- 実行後、REST API（匿名キー）で存在確認：`ui_responses`・`ui_sessions` は200 OK（RLSにより空配列）、
  `ui_report_feed` は `permission denied`（ビューの権限設計どおりで異常ではない）

- **実機テスト送信 → Supabase SQL Editorで `ui_responses` に1行増えていることを確認**。
  データ保存の仕組みが完成した
