# 2026-10-03 集合・解散をＪＲ吹田駅（南口）に変更

## 1. 何を変えたか

松本の判断で、集合・解散を**北口から南口**に変更した。

| | 旧 | 新 |
|---|---|---|
| ① 昼1本目 | 北口12:49発 → 桃山台13:24着 | **南口12:03発 → 桃山台12:48着** |
| ② 昼2本目 | 桃山台13:48発 → 北口14:22で下車 | 桃山台13:48発 → **南口14:32着**（変更なし・終点まで乗る） |
| ③ 夕方1本目 | 北口16:20発 → 桃山台16:55着 | **南口15:55発 → 桃山台16:40着** |
| ④ 夕方2本目 | 桃山台17:18発 → 北口17:52で下車 | 桃山台17:18発 → **南口18:03着**（変更なし・終点まで乗る） |

**②④は便そのものは変わっていない。** もともと南口まで行く便で、北口で降りる運用をやめただけ。

### ①③を差し替えた理由

**旧①③は北口始発で、南口を通らない。** 通し時刻表の南口欄が `··`。
南口から乗ることが物理的にできないので、南口始発の便に入れ替えるしかなかった。

4便とも2系統・始発便であることは通し時刻表の「行先番号」欄で確認済み。

## 2. 得たもの

**記録できる区間が18停留所 → 22停留所に伸びた。**
南口・田中町・吹田市役所前（阪急吹田駅）・アサヒビール会社前 が加わる。
南口は時刻表の最上段＝起点なので、**車内0人から積み上げられる性質は保たれる。**

## 3. 代償

| | 旧 | 新 |
|---|---|---|
| 桃山台の折り返し（昼） | 24分 | **60分** |
| 桃山台の折り返し（夕方） | 23分 | **38分** |
| 拘束（昼） | 約2時間20分 | **約3時間** |
| 拘束（夕方） | 約2時間 | **約2時間40分** |

**昼の60分は入れ替えようがない。** 南口まで行く2系統は桃山台発が毎時 `:48`、
南口発は毎時 `:03` で桃山台着が `:48`。到着と同時刻発になるため、どの時間帯でも60分になる。

拘束が+30分強で済んだのは、**集合から発車までを49分→28分に詰められた**から。
アカウントを事前作成してカードで渡す方式にした（2026-09-26）ので、
その場での登録作業が無くなった。

## 4. ★新しく増えた危険：南口のりば2

**旧版（北口発）は「①のりばに並べばよい。3系統は北口を通らない」で済んでいた。**
取り違えが構造的に起きなかった。**南口はそうはいかない。**

> **ＪＲ吹田駅（南口）のりば2からは、`[2] 桃山台駅ゆき` と `[3] 桃山台駅ゆき` の
> 両方が出る。行先表示はどちらも「桃山台駅」。**

阪急バス公式ののりば情報で確認した。のりば2には **[2][3][4][12][13][19][20]** が集中している。

| | |
|---|---|
| 使うのは | **[2]**（南口 12:03／15:55 発） |
| 乗ってはいけないのは | **[3]**（南口 毎時 `:32` 発。吹田高校・吹高口経由で停留所が違う） |

**行先の「桃山台駅」では見分けられない。行先番号の数字でしか区別できない。**
しかも松本は 2026-09-29 に、まさにこの [3] に乗っている（`docs/log/2026-09-29_pilot.md`）。

**往路も「実験者が見送るまで離れない」を徹底する。**
これまで危険は桃山台側だけだったが、**往路・復路の両方に危険がある**ことになった。
